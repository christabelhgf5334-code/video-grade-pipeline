# 空间层：清晰度 + 柔光辉光 + 暗角

这三样都**需要位置信息**，所以烘不进 LUT，只能挂在渲染链上。它们是把"调过色的视频"
变成"有质感的影像"的分界线，但也是耗时和翻车的主要来源。

---

## 挂载顺序

```
色调映射 → lut3d → 清晰度(unsharp) → 辉光(blend) → 暗角(vignette)
```

- **清晰度在辉光之前**：先锐化再柔化，得到的是"清晰但有光泽"；反过来会得到"糊了之后又强调边缘"，出现锐化白边。
- **暗角最后**：它是全局收尾，放在辉光之后才不会被辉光重新提亮边缘。

---

## 1 · 清晰度（unsharp）

```
unsharp=7:7:0.30:7:7:0
```

| 参数 | 含义 | 建议范围 |
|---|---|---|
| `7:7` | 亮度通道的核大小 | 5×5 更锐利但更脆，7×7 更自然 |
| `0.30` | 亮度增强量 | **0.22–0.32** |
| `7:7:0` | 色度增强量，**必须是 0** | 非 0 会让边缘泛色 |

**调参依据**：0.40 会把暗部噪点一起放大（实测铁板暗部的斑点变明显），0.22 和 0.30 差别不大，
取 0.30。判断标准是**暗部脏不脏**，不是"够不够锐"。

**不适合用的场景**：素材本身噪点重、或者夜景高 ISO。这时锐化只会放大噪声，不如不做。

---

## 2 · 柔光辉光（Pro-Mist 风格的扩散）

人像/美食片里最出效果的一层：高光渗出柔和的暖光，油脂反光有光泽，整体不发干。

```
format=gbrpf32le,
split[m][t];
[t]scale=iw/4:ih/4,gblur=sigma=10,scale=iw*4:ih*4,colorbalance=rm=0.10:gm=0.03:bm=-0.08[g];
[m][g]blend=all_mode=softlight:all_opacity=0.37,
format=yuv420p10le
```

拆解：

| 步骤 | 作用 |
|---|---|
| `format=gbrpf32le` | **必须**。见下方"三个坑" |
| `split` | 复制一路做模糊源 |
| `scale=iw/4` → `gblur` → `scale=iw*4` | 在 1/4 分辨率上模糊再放大。模糊是低频操作，视觉无差，时间省一半 |
| `colorbalance=rm=0.10:gm=0.03:bm=-0.08` | 给辉光加暖色，模拟胶片光晕的偏色 |
| `blend=softlight:all_opacity=0.37` | 柔光混合：既出光晕又轻微提对比，不会整体发灰 |

**参数范围**：

| 参数 | 建议 | 说明 |
|---|---|---|
| `gblur sigma` | 8–14 | 小于 8 看不出光晕，大于 14 会糊成一片 |
| `all_opacity` | 0.30–0.45 | 0.37 是平衡点；超过 0.50 画面发闷 |
| 暖色偏移 | ±0.10 | 超过 0.15 会明显偏橙 |

---

## 三个坑（每个都真实踩过）

### 坑 1：在 YUV 上 blend → 洋红/绿色块

`blend` 按平面混合，`softlight` 会同时施加到 U/V 色度平面，画面直接变成迷幻色块。

**试过且失败的写法**：
- `blend=all_mode=softlight` → 彩块
- `blend=c0_mode=softlight:c1_mode=none:c2_mode=none` → 仍有彩块
- `format=yuv444p10le` 再 blend → 颜色对，但整体发灰变平

**只有 `gbrpf32le`（浮点 RGB）是对的。**

### 坑 2：用 `gbrp16le` 省内存 → 画面暗 33/255

16 位整数 RGB 下 blend 的数值语义和浮点不同，等于换了套数学。实测：平均亮度 166 → 119，
码率 44 Mbps → 149 Mbps（文件大三倍）。

**要省内存只能限线程**：`-filter_threads 2 -threads 6`（已验证输出逐字节相同）。

### 坑 3：把空间层塞进 `primary_chain`

`build_look_lut.py` 的 `primary_chain` 只接受逐像素滤镜。塞 `gblur`/`blend`/`unsharp` 进去
**不会报错**，但烘出来的 LUT 和视频静默不一致——因为恒等色块图上没有"位置"可言。

判据：LUT 套出来的画面 vs 直接跑滤镜链的画面，`mean|d|` 应该 < 2/255。超过就是有空间滤镜混进了 LUT。

## 3 · 暗角

```
vignette=angle=PI/12
```

| 角度 | 强度（平均像素变化） |
|---|---|
| `PI/6` | 13.7/255，太重 |
| `PI/9` | 6.5/255 |
| **`PI/12`** | **3.7/255，推荐** |
| `PI/16` | 2.1/255，几乎看不出 |

竖屏画面用角度值即可，ffmpeg 会按画面比例生成椭圆。别用 `PI/4` 那种，边缘会死黑。

## 代价（4K60 实测，同一台机器）

| 配置 | 速度 | 相对基线 |
|---|---|---|
| 仅 LUT + 暗角 | 4.08 fps | — |
| + 清晰度 | 3.32 fps | +23% |
| + 辉光 | 3.35 fps | +22% |
| + 两者 | 3.07 fps | **+33%** |

375 秒素材、22,500 帧：加空间层后约 2 小时。

---

## 什么时候不要加

- **素材噪点重 / 夜景高 ISO**：锐化放大噪声，辉光把噪点变成脏雾
- **交付给后期继续调**：空间层烘不进 LUT，会让文件无法用 LUT 复现
- **需要严格对版**：如果用户手里有 LUT 想自己套，空间层会造成"看起来不一样"

判断标准：**这批片子是终版交付，还是要继续剪？** 终版加，中间产物不加。
