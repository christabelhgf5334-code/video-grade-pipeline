# Resolve 多级调色顺序教程（Log → 成片）

**一句话主张：先判读，再校正，最后风格。顺序错了后面全废。**

这篇讲的是 Resolve 调色页里「节点里该放什么、按什么顺序放」，不是自动化脚本怎么建工程。
脚本契约见 [resolve-powergrade.md](resolve-powergrade.md)；批量快出片走
[v5-pipeline.md](v5-pipeline.md)。

| 场景 | 走不走这篇 |
|---|---|
| 用户要达芬奇 / 最高效果 / 节点级精修 / 逐帧跟踪 | ✅ 走 |
| Log、S-Log3、V-Log、LogC3、D-Log 等灰片 | ✅ 走，节点 1 放源 LUT |
| PQ / HLG 手机 HDR | ✅ 走，但节点 1 换成色调映射 |
| 只要一个 `.cube` LUT、只要批量快出片 | ❌ 走 ffmpeg 路线 |

> **诚实标注（2026-11-20 更新）**：六节点顺序是自动化契约（`resolve_powergrades.validate_graph()`
> 校验节点数、标签、源 LUT）。**预处理链路已实跑通过**：`look_lab_resolve.py prepare` 在 Resolve
> 21.2.0.6 上产出 `status: preview_complete`（建工程 → 逐镜头 CDL → 六节点 PowerGrade →
> 4 个 look 预览 → 联系表）。**`render --selections` 的最终成片渲染仍未实跑**。
> 文中参数范围来自 ffmpeg 侧已验证配方与调色引擎，作为节点调参起点，不等同于逐项在 Resolve 内复测。
> 凡带数字的实测结果另标来源。

## 1 · 开工前设置（设一次，别每条素材重设）

```text
色彩科学：DaVinci YRGB
时间线 / 输出色彩空间：Rec.709 Scene
位深：10bit（yuv420p10le / HEVC Main10）
```

- **RCM 与节点 1 的源 LUT 二选一**。开了 Resolve Color Management 就把输入色彩空间设成素材真实曲线，
  节点 1 不要再叠一次转换。双重解码的表现是高光撞白、肤色发橙。
- 外部脚本设 Local；**Resolve 必须处于运行状态**（未启动时 `scriptApp('Resolve')` 返回 `None`）。
- 开工前跑一次：`python "<skill-dir>/scripts/doctor.py" --offline`。

## 2 · 第 0 步：判定源头（不可跳）

**判错，后面六个节点全部作废。**

```text
python "<skill-dir>/scripts/detect_source.py" "<素材目录>" --out source_check
```

| 源头 | 节点 1 放什么 | 用错的后果 |
|---|---|---|
| Log（S-Log3 / V-Log / LogC3 / D-Log） | **Log 源 LUT / 色彩空间转换** | 当 HDR 处理 → 发灰发暗、对比丢失 |
| PQ / HLG | **色调映射到 Rec.709** | 当 Log 处理 → 高光撞白、过饱和 |

- 手机 HDR 与 Log 模式写出的元数据常常完全相同（`bt2020` + 10bit + `transfer=unknown`），
  `ffprobe` 分不出来。判定看**动态范围 p95−p05**：被错误解释的 HDR 会把色阶挤在中间。
  实测一条素材 pq 0.494 / sdr 0.388 / hlg 0.359。
- 脚本会把同一帧按 sdr / pq / hlg 各渲一遍打分并出三联图。**分数只是筛子，必须看图确认。**
- **`灰片` ≠ `Log`。** HDR 素材在普通播放器里同样是灰的。
- 曲线实在判不出来，用 `fit_transfer.py` 打分排序，或退回 `genlog` 通用展开（容错最好）。

## 3 · 三级与六节点的映射

| 级别 | 作用范围 | 对应节点 | 能否进 LUT | 解决什么 |
|---|---|---|---|---|
| 一级 | 全局逐像素 | `01`–`03` | ✅ | 曝光准、白平衡准、对比对、影调对 |
| 二级 | 色域 / 空间局部 | `04`–`05` + 窗口分支 | 色域级 ✅ / 空间级 ❌ | **主体与背景的分离感** |
| 三级 | 全画面质感 | 独立分支节点 | ❌ | 辉光、清晰度、暗角、颗粒 |

**关键认知**：一级做十遍也做不出分离感——它是全局的，提亮主体时背景跟着亮。
分离感来自二级的**一正一负：主体 +，背景 −**。这是量级差别，不是参数力度问题。

> 六节点是**颜色骨架**，自动化脚本按节点数和标签校验，**不要重命名或重排**，
> 否则 PowerGrade 契约和写入节点 2 的 CDL 会失效。空间级操作在 Resolve 里另起分支
> （并行节点 / 图层混合 / 窗口 + 跟踪），或走 `render_levels.py` 的三级管线。

## 4 · 六节点逐节点教程

节点名与顺序固定：

```text
01 SOURCE → 02 SHOT BALANCE → 03 TONE MAP → 04 SKIN PROTECT → 05 LOOK → 06 OUTPUT TRIM
```

### 01 SOURCE · 源头转换

- **放**：Log 放厂商源 LUT / 色彩空间转换；PQ/HLG 放色调映射（Hable，`desat=0` 保住彩色物体饱和）。
- **不放**：曝光、白平衡、任何风格。这一格只负责把编码信号还原成 Rec.709 场景。
- 这是整条链的**地基**：换 tonemap 算法会让后面所有 LUT 偏色。
- 判据：输出应是中性、有正常黑位与高光细节的 709 画面，不是「好看」，是「对」。

### 02 SHOT BALANCE · 逐镜头平衡

- **放**：曝光 → 白平衡 → 对比 → 曲线，逐镜头写 CDL（`NodeIndex = "2"`）。
- **不放**：任何 look。CDL 是 shot balancing，不是风格——不然后面每换一个 look 都得重调每个镜头。
- CDL 限制（自动化写入的硬边界）：Slope `0.90–1.10`、Offset `−0.04–0.04`、
  Power `0.92–1.08`、Saturation `0.92–1.08`。
- 每条素材独立推参数，别拿一套参数扫全片。
- **调参优先级：曝光 → 白平衡 → 对比 → 饱和**。前两个错了，后面怎么调都不对。

### 03 TONE MAP · 影调塑形

- **放**：高光肩部滚降、黑位、电影感曲线、以 0.18 中灰为轴的对比。
- 先把影调定死，颜色才有落脚点。暗部比原片沉是刻意的（胶片曲线），
  嫌暗改 `curve` / `shoulder`，**不要整体提亮**。

### 04 SKIN PROTECT · 肤色保护

- **放**：矢量限定器把肤色锁在 **30–37°** 肤色线，或带肤色保护的分亮度饱和。
- **必须在 05 LOOK 之前**：look 会推色相，事后救不回来。
- 验证用 `scripts/check_skin.py`，**必须比「一级」和「一级+二级」两帧**；
  拿原始 vs 成品比会把一级的正常变化误读成二级泄漏。

### 05 LOOK · 风格

- **放**：胶片曲线、分离色调（高光暖 / 阴影冷）、青橙、色域级二级
  （食物 / 天空 / 植被分色域微调，阈值避开皮肤受光面）。
- **先出并排预览让用户选，不要自己替他定 look**：同一帧、同一裁切、同尺寸并排，
  跨帧比较等于在比较镜头。
- 本体系 look LUT 是为 **Log 信号**标定的。HDR 素材若未在 01 完成色调映射就套，
  实测饱和度 0.585–0.673（正确值 0.432）且高光撞白。
- **LUT 不要叠用**：合并版套原始素材，或分级 LUT 串联，二选一。

### 06 OUTPUT TRIM · 输出收口

- **放**：整体微调、限幅防溢出、锁死 Rec.709 gamut。
- **最后一道**。前面任何节点都不许做输出级限制——提前钳死会让后续节点压不回影调。

## 5 · 节点内部的操作顺序（一级）

无论用节点还是 `grade_engine.py`，顺序一致：

```text
编码信号 → 解码曲线 → 线性光 → 白平衡 → LGG → 对比 → 色调曲线
        → Rec.709 编码 → 饱和(肤色保护) → 高光滚降 → 分离色调
```

白平衡要在**线性光**里做；饱和放在 709 编码之后并带肤色保护；高光滚降和分离色调收尾。
`color-engine.md` 有 10 种输入曲线与五个内置 look 的完整参数。

---

## 6 · 顺序约束：为什么不能换

| 颠倒 | 现象 | 依据 |
|---|---|---|
| 未做源头转换就套 look | 饱和度 0.585–0.673（正确 0.432）、高光撞白 | 实测 |
| 三级提前到二级前 | halation 光晕把二级刚拉出的分离糊掉 | 三级管线 |
| 二级提前到一级前 | 在曝光还错的画面上分区，白推 | 三级管线 |
| 肤色保护放到 LOOK 之后 | look 已推色相，事后救不回 | 引擎顺序 |
| 输出级限制放到前面节点 | 后续节点全被钳死 | 通用 |
| RCM 与节点 1 双重转换 | 高光撞白、肤色发橙 | 工程设置 |

**总顺序**：

```text
判源头 → 色调映射/源 LUT → 一级(全局) → 二级(分区) → 三级(质感) → 输出收口 → 编码(CFR)
```

## 7 · 二级：分离感才是「最牛逼」的分水岭

- **一正一负**：主体提亮 / 保饱和，背景压暗 / 降饱和。分离感来自**压背景**，不来自推主体。
  实测（夜市烤串素材，V5 look + 分区 + 辉光）：分离 0.194 → 0.230（**+19%**）。
  ⚠️ 早期流传的「+64%」用的是「主体 vs 画面边缘」指标，被暗角污染，已作废。
  复核必须用 `measure_levels.py`（主体 vs 紧邻背景环 + 背景细节σ + 角/中比值）。
- **色域级 vs 空间级别混**：按颜色选中（限定器）能烘进 LUT；按位置选中（窗口 / 跟踪）
  **烘不进 LUT**，必须 Resolve 节点。别指望一个 LUT 造景深。
- 限定器：**先聚类再写**（`scripts/analyze_domains.py` 给色相家族与占比），一律软边
  `smoothstep`，不用硬阈值；榨不出区分度就承认，改用背景做分离。
- 窗口 / 遮罩**必须看一眼画面再定分界线**。实测反例：默认 `band 0.30` 把上排烤串
  （从 18% 开始）误判成背景压暗。羽化 5%–8% 画幅高度，硬边会留下可见的界。
- 需要逐帧跟踪、物体级窗口时，只有 Resolve 能做（ffmpeg 只能静态遮罩）。

## 8 · 三级质感层的顺序与参数起点

```text
清晰度 → Pro-Mist 辉光 / halation → 暗角 → 颗粒
```

| 层 | 参数起点 | 坑 |
|---|---|---|
| 清晰度 | `unsharp 7:7:0.30`，**色度增强必须为 0** | 0.40 会放大暗部噪点；判据是暗部脏不脏，不是够不够锐 |
| 辉光 | 1/4 分辨率模糊再放大，sigma 8–14，opacity 0.30–0.45 | 必须在 RGB / 浮点域做；YUV 上混合会出色块 |
| 暗角 | `PI/12`（约 3.7/255） | `PI/6` 太重（13.7/255），几乎只见氛围不见明暗才对 |
| 颗粒 | **默认关闭**，要用 1–3 | 4K60 强度 5 实测冲到 **300+ Mbps**，逐帧随机不可压缩 |

三级放前面的代价见第 6 节。参数细节见 `spatial-layer.md`。

## 9 · 交付前 QA（只看画面不够）

```text
python "<skill-dir>/scripts/verify_delivery.py" --src "<源目录>" --out "<成片目录>" --fps 60
```

示波器硬指标（`video-grade-pipeline` 的 `scopes.py`）：**溢出 <1%、死黑 <1%、R−B <±0.10、肤色色相 30–37°**。

- 多镜头**必须做镜头匹配**：五条成片实测中间调跨度 0.538、色偏跨度 0.379，
  每条单独都「对」，连起来是五条不同的片子；匹配后跨度 0.538 → 0.136（**收窄 75%**）。
- **饱和度默认不匹配**：瀑布本就该比水果淡，那是内容不是缺陷。同场景才加 `--match-saturation`。
- Quality Gate 不满足不许说完成：Resolve 任务 `Complete`、`verify_delivery.py` 全通过、
  HEVC Main10 / `yuv420p10le` / BT.709、竖屏 `2160×3840`、`qc_report.json` 为 `complete`、
  `check_skin.py` 判定肤色「守住」。
- **不要把 ffmpeg 结果说成 Resolve 结果。**

## 10 · 一页速查

1. `doctor.py` 自检；项目设 DaVinci YRGB / Rec.709 Scene / 10bit。
2. `detect_source.py` 判源头，**看图确认**，定节点 1 是源 LUT 还是色调映射。
3. 套六节点 PowerGrade，顺序与标签不改。
4. 01 只解码 → 02 逐镜头 CDL（±10% 内）→ 03 影调 → 04 锁肤色 → 05 出 look 预览让用户选 → 06 收口。
5. 二级做「主体 + / 背景 −」，限定器软边、看画面定界、`check_skin.py` 比两帧。
6. 三级按 清晰度 → 辉光 → 暗角 → 颗粒（默认关）挂分支节点。
7. 示波器四项 + 镜头匹配 + `verify_delivery.py`，逐条过 Quality Gate。
8. 交付时主动说明：源头类型与走的路线、文件是严格 CFR（软件显示 30 帧是工程帧率）、LUT 不叠用。
